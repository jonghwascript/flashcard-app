# Spec Delta

## Purpose

페이지 작성자가 공통 레이아웃 패턴을 조합하여 콘텐츠의 간격, 너비, 정렬과 반응형 전환을 예측할 수 있도록 한다. 문서화된 옵션과 중첩 시의 동작을 일관된 재사용 계약으로 제공한다.

## ADDED Requirements

### Requirement: 수직 흐름과 간격 프리셋
수직 흐름 패턴은 기본 간격 1.5rem과 small 0.75rem, normal 1rem, large 3rem을 SHALL 제공한다. 재귀 옵션은 인접 자손 사이에 간격을 한 번 적용하고 false에서는 비활성화된다. 하단 밀기 대상은 남는 세로 공간을 사용한다.

#### Scenario: 기본값과 명시 옵션
- **WHEN** 수직 흐름에 옵션을 생략하거나 small, normal, large를 각각 지정한다
- **THEN** 간격은 각각 1.5rem, 0.75rem, 1rem, 3rem이며 루트 글꼴에 따라 환산된다

#### Scenario: 재귀와 하단 밀기 조합
- **WHEN** 충분한 높이의 수직 흐름에서 재귀 옵션과 직계 자식의 하단 밀기를 사용한다
- **THEN** gap과 마진의 이중 간격 없이 자손 간격이 적용되고 하단 대상의 자동 마진이 유지된다

### Requirement: 수평 묶음의 정렬과 간격
수평 묶음은 기본 중앙 정렬과 1rem 간격, 시작·양끝 정렬, small 0.5rem, normal 1rem, large 1.5rem 간격을 SHALL 제공하며 공간이 부족하면 줄바꿈한다. 중첩된 수직 흐름의 간격을 기본값으로 물려받지 않는다.

#### Scenario: 중첩된 묶음
- **WHEN** 큰 간격의 수직 흐름 안에서 수평 묶음의 옵션을 생략하거나 간격 프리셋을 선택한다
- **THEN** 묶음 자체의 기본값 또는 선택한 간격이 적용되고 항목은 가용 너비에 맞게 줄바꿈한다

### Requirement: 경계와 콘텐츠 너비 패턴
구분선 흐름, 박스, 중앙 정렬, 전체 폭 콘텐츠 열 패턴은 가이드의 기본값과 옵션을 SHALL 제공한다. 박스의 반전·패딩·테두리·둥글기 옵션, 중첩 박스 색상, 중앙 정렬의 텍스트·고유 크기 정렬을 지원한다. 전체 폭 옵션은 콘텐츠 열의 직계 자식에만 적용된다.

#### Scenario: 박스 옵션과 중첩
- **WHEN** 반전 박스 안에 별도 박스와 컴포넌트 색상이 지정된 자손을 배치한다
- **THEN** 바깥 박스의 색상 상속이 중첩 박스와 컴포넌트의 명시적 색상을 덮지 않는다

#### Scenario: 콘텐츠 열과 전체 폭
- **WHEN** 최대 너비가 설정된 콘텐츠 열의 한 직계 자식만 전체 폭으로 지정한다
- **THEN** 해당 자식은 바깥 열까지 확장되고 나머지는 최소 양쪽 여백과 콘텐츠 최대 너비를 따른다

### Requirement: 공간에 따른 배치 전환
사이드바, 전환형 행, 자동 격자는 가이드의 너비·간격 변수에 따라 SHALL 배치된다. 사이드바는 두 자식 구조를 사용하고, 전환형 행은 임계값과 항목 수에 따라 줄바꿈하며 다섯 항목 이상에서는 각 항목이 한 행을 차지한다.

#### Scenario: 컨테이너 폭 변화
- **WHEN** 패턴의 컨테이너를 좁히거나 넓힌다
- **THEN** 사이드바와 전환형 행은 가용 공간에 맞춰 줄바꿈하고 자동 격자는 가능한 열 수를 사용한다

#### Scenario: 전환형 행의 항목 수
- **WHEN** 넓은 전환형 행에 다섯 개 이상의 직계 자식을 배치한다
- **THEN** 모든 항목이 각각 한 행을 차지한다

### Requirement: 세로 커버의 남은 공간 배분
세로 커버는 지원 환경에서 동적 뷰포트 높이, 그 외에는 뷰포트 높이를 최소 높이로 SHALL 사용한다. 중앙 대상은 위아래 자동 마진으로 남은 공간을 나누며 콘텐츠가 많으면 영역이 확장된다. 위아래 콘텐츠 높이가 다를 때 뷰포트의 기하학적 중앙을 보장하지 않는다.

#### Scenario: 비대칭 주변 콘텐츠
- **WHEN** 높이가 서로 다른 상단·하단 콘텐츠 사이에 중앙 대상을 배치한다
- **THEN** 남은 공간의 위아래 자동 마진은 균등하며 중앙 대상이 첫째 또는 마지막인 경우에도 자동 마진이 유지된다

### Requirement: 미디어와 겹침 패턴
미디어 프레임, 가로 스크롤 행, 중앙 겹침, 아이콘 행은 가이드에 명시된 비율·크기·여백 옵션을 SHALL 제공한다. 프레임은 기본 16:9와 cover 자르기, 스크롤 행은 항목 축소 없는 가로 스크롤, 중앙 겹침은 기준 영역 내 중앙 배치와 선택적 크기 제한을 제공한다.

#### Scenario: 미디어와 가로 스크롤
- **WHEN** 서로 다른 비율의 미디어를 프레임에 넣거나 행보다 넓은 항목 집합을 배치한다
- **THEN** 미디어는 프레임을 비율 유지하여 채우고 행은 항목을 축소하는 대신 내부 가로 스크롤을 제공한다

#### Scenario: 제한된 겹침과 아이콘
- **WHEN** 크기가 정해진 기준 영역에 여백 제한을 둔 중앙 콘텐츠와 텍스트가 있는 아이콘 행을 배치한다
- **THEN** 중앙 콘텐츠는 최대 크기를 지키며 내부 스크롤할 수 있고 아이콘은 글꼴 기준 크기·기준선·독립 간격을 따른다
